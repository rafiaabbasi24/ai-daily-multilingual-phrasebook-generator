# Context‑Aware Multilingual Phrasebook Generator

## Overview
The **Context‑Aware Multilingual Phrasebook Generator** is a FastAPI‑based service that creates concise, context‑specific phrasebooks in multiple languages. Users submit a short description of a scenario (e.g., “ordering coffee in a Paris café”), and the system returns a curated list of useful expressions translated into the target language(s).  

Key capabilities:
- **Context extraction** using a transformer model (e.g., `distilbert-base-multilingual-cased`) to identify the domain and intent.
- **Semantic similarity** powered by Jina AI embeddings to retrieve the most relevant phrases from a SQLite‑backed phrase repository.
- **Dynamic translation** via Hugging Face Transformers (e.g., `Helsinki-NLP/opus‑mt` models) to generate multilingual outputs on‑the‑fly.
- **RESTful API** built with FastAPI, ready for containerisation or serverless deployment.

## Features
- Multi‑language support (currently English, French, Spanish, German, Mandarin; extensible).
- Context‑aware phrase ranking for higher relevance.
- SQLite persistence for phrase data, embeddings, and usage logs.
- OpenAPI documentation automatically generated by FastAPI.
- Simple Dockerfile for production deployment.

## Installation

### 1. Clone the repository
```bash
git clone https://github.com/your-org/context-aware-phrasebook.git
cd context-aware-phrasebook
```

### 2. Create a virtual environment
```bash
python -m venv .venv
source .venv/bin/activate   # On Windows: .venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Initialise the SQLite database
```bash
python -m phrasebook.db init
```
This command creates `phrasebook.db` and populates it with a minimal seed phrase set. You can later import a larger phrase corpus using `python -m phrasebook.db import <path_to_csv>`.

## Configuration
Environment variables can be placed in a `.env` file at the project root:

| Variable | Description | Default |
|----------|-------------|---------|
| `HOST` | Host address for Uvicorn | `0.0.0.0` |
| `PORT` | Port for the API | `8000` |
| `LOG_LEVEL` | Logging level (`debug`, `info`, `warning`, `error`) | `info` |
| `MAX_PHRASES` | Maximum number of phrases returned per request | `10` |
| `EMBEDDING_MODEL` | Jina embedding model identifier | `jinaai/jina-embeddings-v2-base-en` |
| `TRANSLATION_MODEL_EN_FR` | Hugging Face model for EN→FR translation | `Helsinki-NLP/opus-mt-en-fr` |
| `TRANSLATION_MODEL_EN_ES` | Hugging Face model for EN→ES translation | `Helsinki-NLP/opus-mt-en-es` |
| `...` | Add more translation model variables as needed | – |

Load variables automatically with `python-dotenv` (already included in `requirements.txt`).

## Running the Service

### Development mode
```bash
uvicorn phrasebook.main:app --reload --host $HOST --port $PORT
```
Open http://localhost:8000/docs to explore the interactive OpenAPI UI.

### Production mode (Docker)
```bash
docker build -t phrasebook .
docker run -d -p 8000:8000 --env-file .env phrasebook
```

## API Endpoints

### `POST /generate_phrase`
Generate a phrasebook for a given context.

**Request body (JSON)**
```json
{
  "context": "I need to ask for directions in Tokyo",
  "target_languages": ["ja", "en"],
  "max_phrases": 8
}
```

**Response (JSON)**
```json
{
  "context": "I need to ask for directions in Tokyo",
  "phrases": {
    "en": [
      "Excuse me, could you tell me how to get to the train station?",
      "... more English phrases ..."
    ],
    "ja": [
      "すみません、駅への行き方を教えていただけますか？",
      "... more Japanese phrases ..."
    ]
  }
}
```

### `GET /health`
Simple health‑check endpoint returning `200 OK`.

## Example Usage (Python client)

```python
import httpx

api_url = "http://localhost:8000/generate_phrase"
payload = {
    "context": "booking a hotel room in Berlin",
    "target_languages": ["de", "en"],
    "max_phrases": 5
}

response = httpx.post(api_url, json=payload)
response.raise_for_status()
data = response.json()
print(data["phrases"]["de"])
```
